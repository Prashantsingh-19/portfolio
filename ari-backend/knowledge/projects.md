# Prashant's Health-Tech and NLP Projects

## Onco-Directory (health tech platform)
Onco-Directory is a verified professional network for oncologists that Prashant built with Next.js, Supabase, Clerk and TypeScript, deployed on Vercel. Trust is tied to medical licence IDs, so there is no spam and no manual approval gate. Doctors get a shared feed, a graph-based connection engine that suggests peers by specialisation, and direct messaging for referrals and consultations. It is designed on the assumption that a doctor's time is scarce and trust is hard to earn. Live at onco-directory.vercel.app.

## OncoAssistant — Clinical Trials Dashboard
OncoAssistant is a competitive-intelligence dashboard for pharma strategy teams, built with Next.js, Supabase, Recharts and ECharts. It maps where each competitor's drug trials stand (completed, active and newly initiated) and which cancer targets they cover. The key insight it surfaces: when a company hits efficacy targets, new trial volume drops and approval investment rises, and that shift is visible in the data. Live at oncoassistant.vercel.app.

## Political Discourse Topic Modelling
Prashant built an LDA topic-modelling pipeline in Python with scikit-learn to analyse political leaders' speeches. It comes with an interactive dashboard of topic weights, word clouds and domain analysis, published on his portfolio site. Code: github.com/Prashantsingh-19/Topic-Modelling.
